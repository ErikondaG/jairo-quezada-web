# Título del Proyecto

Jairo Quezada Web

## Descripción

Sitio web carta de presentación para Jairo Quezada, cantante, compositor, autor y guitarrista chileno.

## Construido Con 🛠️

- [Next.js](https://nextjs.org/) - Framework
- [GSAP](https://gsap.com/) - Librería de animaciones
- [Lenis](https://lenis.studiofreight.com/) - Librería de smooth scrolling
- [Netlify](https://www.netlify.com/?utm_source=copilot.com) - Hosting
- [Tailwind](https://tailwindcss.com/) - Framework CSS
